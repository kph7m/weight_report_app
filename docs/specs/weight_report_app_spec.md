# Weight Report App スペック

## 1. 目的

Weight Report App は、体重を日次でローカル記録し、当日の体重、直近の履歴、日ごとの 7 日平均、および目標体重までの差を確認する体重管理アプリです。

## 2. 対象・技術構成

- UI: Flutter / Material 3
- 状態管理: Riverpod
- ローカルデータベース: Isar
- フォント: Noto Sans JP
- 主な配布対象: Android
- 画面の日時表示: 端末のローカル日付を使用し、画面上に `JST` の文言は表示しない

## 3. 画面遷移

1. アプリ起動時にローカル DB から体重記録を読み込む。
2. 端末上の本日の日付に対応する記録が存在する場合は、レポート画面を表示する。
3. 本日分が存在しない場合は、体重入力画面を表示する。
4. 体重入力画面で有効な体重を確定して保存すると、考え中表示を 3 秒間表示した後、レポート画面へ遷移する。
5. レポート画面の「体重入力」アイコンを押すと、本日分の有無にかかわらず体重入力画面へ遷移する。
6. 同じ日に再入力して確定した場合は、本日分の既存記録を更新する。

## 4. 画面仕様

### 4.1 体重入力画面（ホーム画面）

#### 表示

- `screen-animations/weight-entry-start-screen-reference.png` を基準とした、淡いピンク基調の画面とする。
- 雲、星、ハートなどの装飾、入力位置を指すキャラクター、および下部の大きな角丸体重入力カードを表示する。
- 初期値は `00.0 kg` とし、数値を大きく、単位 `kg` を右側に表示する。
- 入力前および入力中は `character_pointing_input.png` を表示する。
- 保存処理を開始した後は `character_thinking.png` を表示する。
- ホーム画面には、履歴表、7 日平均、目標体重までの差などのレポート情報を表示しない。

#### 入力制約

- 数字と小数点のみ入力できる。
- 整数部は 1〜3 桁、小数部は最大 1 桁とする。
- 入力可能な最大値は `999.9 kg` とする。
- `.5` のように整数部を省略した形式は受け付けない。
- 自動保存の確定形式は、小数点以下を必ず 1 桁含む `整数部1〜3桁.小数1桁` とする。
- 自動保存の最小値は `30.0 kg` とする。`30.0 kg` 未満では保存・画面遷移を行わない。

#### 保存と遷移

- 入力欄からフォーカスが外れた時点で入力値を判定する。
- `30.0 kg` 以上、`999.9 kg` 以下で、小数点以下 1 桁まで入力された有効値の場合に自動保存する。
- 保存中の重複実行を防止する。
- 保存成功後は考え中キャラクターを 3 秒間表示し、レポート画面へ遷移する。
- 保存失敗時は共通エラーダイアログを表示し、レポート画面へ遷移しない。

### 4.2 レポート画面

#### ヘッダー

- 最新記録を「本日の体重」として小数点以下 1 桁および `kg` 単位で表示する。
- 最新記録の測定日を `yyyy/M/d（曜日）` 形式で表示する。
- 日付や表見出しに `JST` は表示しない。

#### 直近 7 日間の体重記録

- 記録日が新しい順に最大 7 件を表示し、7 件未満の行は `--` で表示する。
- 各行には次の項目を表示する。
  - 日付: `yyyy/M/d（曜日）`
  - 体重: 小数点以下 1 桁 + `kg`
  - 前日比: 当該行の体重と、その次に古い記録の体重との差
  - 7 日平均: 当該行の日付を含む過去 7 暦日（当日から 6 日前まで）に存在する記録の平均
- 7 日平均は、表全体で同じ値を使い回さず、各行の日付を基準に個別計算する。
- 7 日の期間内に記録がない日は分母に含めず、存在する記録だけで平均を計算する。
- 7 日平均は小数点以下 2 桁 + `kg` で表示する。
- 例: `7/15 = 85.6 kg`、`7/16 = 85.3 kg` の 2 記録だけがある場合、7/15 の平均は `85.60 kg`、7/16 の平均は `85.45 kg` とする。
- 前日比は増加をピンクの `+`、減少を青の `−`、変化なしを `±` で表示する。比較対象がない場合は `±0.0` とする。

#### 目標・メッセージ

- 目標体重は固定値 `75.0 kg` とする。
- 「目標まであと」は `max(最新体重 - 75.0, 0)` を小数点以下 1 桁で表示する。
- 最新体重、前回記録との差、および応援文を含むメッセージパネルを表示する。
- レポート応援キャラクター `character_report.png` を表示する。

#### 体重入力ショートカット

- 測定日および「直近７日間の体重記録」タイトルエリアの右側に、`weight_input_icon.png` を画像そのものの見た目で表示する。
- アイコン画像の周囲にアプリ側で黒い背景や黒い縁取りを追加しない。
- アイコン全体が縦横とも見切れないサイズで表示する。
- アイコンには「体重入力画面を開く」のボタンセマンティクスを設定する。
- タップ時は現在のレポート画面を置き換えて、強制的に体重入力画面を表示する。

### 4.3 読み込み状態

- DB 読み込み中は `CircularProgressIndicator` を表示する。
- DB 読み込みに失敗した場合は `読み込みに失敗しました: <エラー内容>` を表示する。

## 5. データ仕様

### 5.1 保存先

- 体重記録は、アプリの Documents ディレクトリにある Isar のローカル DB に保存する。
- クラウドや外部サーバーへの送信は行わない。
- 記録はアプリ再起動後も保持する。

### 5.2 体重記録（`WeightEntry`）

| 項目 | 型 | 内容 |
| --- | --- | --- |
| `id` | Isar `Id` | 自動採番されるレコード ID |
| `date` | `DateTime` | 端末ローカル時刻に基づく記録日。時刻を 00:00:00 に正規化して保存 |
| `weightKg` | `double` | kg 単位の体重 |
| `createdAt` | nullable `DateTime` | 初回作成日時 |

- 1 日につき 1 レコードとする。
- 本日分が既に存在する場合、`weightKg` を更新し、新規レコードは追加しない。
- 更新時も既存の `createdAt` を保持する。
- 取得結果は `date` の降順（新しい日付が先）とする。
- Isar のスキーマ・マイグレーションに関する開発時の回復可能エラーでは、既定 DB ファイルを削除して再作成する場合がある。

## 6. エラー表示仕様

- アプリ内で捕捉したエラーは、タイトル `エラーが発生しました` のダイアログで表示する。
- 本文にはエラー内容を表示する。
- スタックトレースからアプリ内の発生箇所を特定できる場合は、`発生箇所: ファイル名:行番号:列番号` を併記する。
- ダイアログは `OK` ボタンで閉じられる。
- Flutter フレームワークエラーおよび未捕捉の非同期エラーも共通エラーハンドラーへ送る。

## 7. アセット・アプリアイコン仕様

- アプリ内画像は `assets/images/` に配置する。
- 体重入力ショートカットには `assets/images/weight_input_icon.png` を使用する。
- アプリアイコンの原画には `assets/images/app_icon.png` を使用する。
- Android の通常アイコンおよび Adaptive Icon、iOS アイコンはランチャーアイコン生成設定から出力する。
- Android Adaptive Icon の背景色はピンク `#F75AA0` とする。
- iOS 向けアイコン生成時はアルファチャンネルを除去する。
- 提供された画像は、明示的な指示がない限り再生成・描き直し・デザイン変更を行わない。

## 8. 受け入れ条件

- 本日分の記録がない場合、起動時に体重入力画面が表示される。
- 本日分の記録がある場合、起動時に本日のレポート画面が表示される。
- `30.0`〜`999.9` の範囲かつ小数点以下 1 桁の体重を入力し、フォーカスを外すと自動保存される。
- `30.0 kg` 未満、不正な文字、2 桁以上の小数、または `999.9 kg` を超える値は保存されない。
- 保存成功後、考え中キャラクターが 3 秒間表示されてからレポート画面へ遷移する。
- 同じ日の再入力では本日分が更新され、1 日 1 件が維持される。
- 保存した記録はアプリ再起動後も確認できる。
- レポート表には新しい順に最大 7 件が表示される。
- 各行の 7 日平均は、その行の日付を含む過去 7 暦日内に存在する記録のみから計算される。
- 7/15 に 85.6 kg、7/16 に 85.3 kg の記録がある場合、それぞれ `85.60 kg`、`85.45 kg` と表示される。
- レポート画面に `JST` の文言は表示されない。
- レポート画面の体重入力アイコンは見切れず、黒背景・黒縁なしで表示され、タップすると体重入力画面へ遷移する。
- 目標体重 `75.0 kg` と、最新体重から算出した残り体重が表示される。
- エラー発生時はエラー内容と、特定可能な場合は発生箇所がダイアログに表示される。
