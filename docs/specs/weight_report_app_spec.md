# Weight Report App スペック

## 目的

Weight Report App は、Android 向けに体重を日次で記録し、履歴・平均・目標達成状況を確認できる体重管理アプリです。

## 対象プラットフォーム

- Flutter stable channel
- Android

## 現在の主要機能

1. 今日の体重を入力できる。
2. 体重履歴を一覧で確認できる。
3. 直近 7 日平均を表示できる。
4. 目標体重 75kg までの進捗を表示できる。
5. Material 3 に準拠した UI を利用する。
6. Riverpod による状態管理を利用する。
7. Isar によるローカル永続化を利用する。

## 画面仕様

### ホーム画面

- アプリ起動時は、`screen-animations/weight-entry-start-screen-reference.png` を基準にした体重入力画面を表示する。
- ホーム画面の役割は、キャラクターによる体重入力案内と、今日の体重入力・保存のみに限定する。
- 入力前は、入力エリアを指差すキャラクター画像で入力位置を案内する。
- 起動時の入力画面は、淡いピンク基調の背景、雲・星・ハートなどの装飾、入力エリアを指差すキャラクター、下部の大きな角丸カード型体重表示で構成する。
- 未入力時の体重表示は `00.0 kg` とし、数値を大きく、単位 `kg` を右側に小さく表示する。
- 体重入力は数値のみ、小数点第 1 位まで、最大 `999.9 kg` とする。
- 体重表示カードは白〜淡色の背景、ピンクの枠線、角丸、軽い影を付け、入力可能な領域であることが分かる見た目にする。
- `30.0 kg` 以上かつ小数点第 1 位まで入力したあと、キーボード表示をなくして入力確定したら、入力された体重と入力した日付をアプリ内 DB に保存する。
- 体重入力後はハイタッチ画像やお祝い画像を表示せず、キャラクター画像を考え中状態（`character_thinking.png`）に変更する。
- 体重の保存が成功したら、考え中状態を 3 秒表示してからレポート画面へ遷移する。
- ホーム画面には、保存済みの体重履歴、直近 7 日平均、目標体重までの進捗などのレポート情報を表示しない。

### レポート画面

- 保存済みの体重履歴を確認するための画面として表示する。
- 保存済みの体重履歴を表示する。
- 直近 7 日平均を表示する。
- 目標 75kg までの進捗を表示する。
- その他、体重管理に役立つ情報を表示する。例: 最新体重、前回記録との差分、記録日数、週ごとの傾向、目標達成状況。
- レポート画面からホーム画面へ戻り、次の体重入力を行える。

## エラー表示仕様

- アプリ内でエラーが発生したら、`エラーが発生しました` というタイトルのダイアログを表示する。
- エラーダイアログには、発生したエラー内容と、特定できる場合はファイル名・行番号・列番号を本文として表示する。
- エラーダイアログは `OK` ボタンで閉じられる。

## データ仕様

### 体重記録

- 記録日
- 体重

## 受け入れ条件

- ユーザーはホーム画面で今日の体重を入力し、ローカルに保存できる。
- 体重入力は数値のみ、小数点第 1 位まで、最大 `999.9 kg` に制限される。
- 入力体重が `30.0 kg` 未満の場合、入力前の指差しキャラクターのまま保存・遷移しない。
- 入力体重が `30.0 kg` 以上かつ小数点第 1 位まで入力済みで、キーボード表示をなくして入力確定した場合、入力された体重と入力した日付がローカルに保存される。
- 体重の保存が成功したら、ホーム画面のキャラクター画像が考え中状態に変わり、3 秒後にレポート画面へ遷移する。
- 保存した体重はアプリ再起動後も確認できる。
- アプリ内でエラーが発生した場合、エラー内容と、特定できる場合はファイル名・行番号・列番号がダイアログで表示される。
- レポート画面では、体重履歴が記録日と体重が分かる形で表示される。
- レポート画面では、直近 7 日分の記録がある場合、平均体重が表示される。
- レポート画面では、目標体重 75kg に対する進捗が表示される。

## 画面イメージ/アニメーション

画面イメージ、画面遷移、操作アニメーションは `screen-animations/` に格納します。ファイル名は、対象画面や操作が分かる名前にします。

例:

- `home-screen.png`
- `weight-entry-flow.gif`
- `history-scroll.mp4`

現在の登録済み素材:

- `screen-animations/weight-entry-start-screen-reference.png`: アプリ起動時に表示する体重入力画面の参考画像。
- `../screenshots/startup-weight-entry-screen.png`: 実装後にキャプチャしたアプリ起動時の体重入力画面。
- `../screenshots/home-screen.png`: 実装後にキャプチャしたホーム画面。
- `../screenshots/home-screen-thinking.png`: `30.0 kg` 以上の入力後に考え中キャラクターを表示するホーム画面。
- `../screenshots/report-screen.png`: 実装後にキャプチャしたレポート画面。
- `screen-animations/characters/character-pointing-input.png`: 入力前に入力エリアを案内するキャラクター画像。
