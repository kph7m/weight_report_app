# AIコメント生成機能

## 概要

体重入力後にOpenAI Responses APIを利用してコメントを生成する。

生成したコメントはレポート画面へ表示し、アプリ内DBへ保存する。

---

# API

## 使用API

Responses API

`previous_response_id`は使用しない。

毎回独立したリクエストとして実行する。

---

# API送信データ

## プロフィール

- 身長
- 目標体重

## 今日のデータ

- 今日の体重
- 前日比
- 目標体重までの残り

## 直近7日間

- 日付
- 体重

## 直近7日平均

- 日付
- 7日平均

## 前回コメント

前日に生成したコメント。

初回は空文字とする。

---

# システムプロンプト

```text
あなたはダイエットアドバイザーです。

以下のルールでコメントを生成してください。

・親しみやすく、少しお嬢様口調の優しい話し方
・前向きに励ます
・300文字以内
・数値の変化を必ずコメントする
・直近7日間の傾向を考慮する
・前回コメントと似た文章を避ける
・絵文字は使用しない
・Markdownは使用しない
・文章のみ返答する
```

---

# ホーム画面

体重入力確定後、`character_thinking.png`を表示する。

入力UIは操作不可とする。

---

# API待機

Responses APIの返却待ち中は`character_thinking.png`を表示し続ける。

---

# API成功

API返却後、すぐにレポート画面へ遷移する。

現在実装されている3秒待機処理は削除する。

---

# レポート画面

APIから返却されたコメントを左下コメント欄へ表示する。

現在表示している固定コメントは削除する。

---

# DB

OpenAIから返却されたコメントを保存する。

## 保存項目

- 日付
- 体重
- AIコメント

翌日は前日のAIコメントを取得してAPIへ送信する。

---

# エラー

API失敗時は「今日はコメントを生成できませんでした。」を表示する。

DBには保存しない。

---

# APIキー

設定画面に保存されたAPIキーを利用する。

---

# 実装方針

Repositoryパターンを維持する。

既存構成に合わせて以下を追加する。

- Model
- Repository
- Service

既存コードの可読性・保守性を優先して実装する。
