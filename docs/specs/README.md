# スペック格納ディレクトリ

このディレクトリは、SSD（Spec-Driven Development）で利用するスペックファイルと画面イメージ/アニメーション素材を管理する場所です。

## 構成

- `weight_report_app_spec.md`: アプリ全体の要求・画面・データ・受け入れ条件をまとめるスペックファイル。
- `screen-animations/`: 画面イメージ、画面遷移アニメーション、操作イメージの素材置き場。

## 運用ルール

- 機能追加、仕様変更、不具合修正でユーザー体験や振る舞いが変わる場合は、実装と同じ変更単位でスペックファイルも更新します。
- 画面の見た目や遷移が変わる場合は、必要に応じて `screen-animations/` に画像・GIF・動画・説明ファイルを追加または更新します。
- スペックと実装が食い違う場合は、実装前にどちらを正とするかを決め、決定内容をスペックに反映します。
