# 画面イメージ/アニメーション置き場

SSD（Spec-Driven Development）で参照する画面イメージ、画面遷移アニメーション、操作イメージをこのディレクトリに格納します。

## 推奨ファイル例

- PNG/JPEG: 静的な画面イメージ
- GIF/WebP: 短い操作アニメーション
- MP4: 画面遷移や長めの操作動画
- Markdown: 画像や動画に補足説明が必要な場合

## 命名ルール

対象画面や操作が分かる名前にします。

例:

- `home-screen.png`
- `weight-entry-flow.gif`
- `history-scroll.mp4`

## 登録済み素材

- `weight-entry-high-touch-flow.png`: 入力前、入力後、ハイタッチ、記録完了までの画面フロー案。
- `characters/character-pointing-input.png`: 入力前に入力エリアを案内するキャラクター画像。
- `characters/character-high-touch.png`: 入力後にハイタッチを求めるキャラクター画像。
- `characters/character-celebration.png`: 記録完了後にお祝いするキャラクター画像。
